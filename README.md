## Overview

The repository contains one self contained HTML document, [`swerchanumv2.html`](swerchanumv2.html). It presents the Swechanum technical reference as a structured documentation site instead of a collection of separate pages.

## Documentation coverage

The site organizes engineering information for:

- Systemcore and Motioncore architecture
- A301 mechanical systems
- Swerve and mecanum drivetrains
- Programming and controller setup
- Limelight vision
- Testing and troubleshooting
- Technical resources and project credits

## Design

The interface uses a minimalist black, gray, and white visual system with Space Grotesk, IBM Plex Sans, and IBM Plex Mono typography. It includes a sticky navigation bar, searchable documentation, responsive content cards, technical tables, callouts, checklists, code blocks, and mobile layouts.

The page loads its fonts from Google Fonts. An internet connection may be required for the intended typography, while the documentation content itself remains inside the HTML file.

## Use

Open the documentation directly in a modern browser:

```text
swerchanumv2.html
```

No build process or local web server is required. For the best behavior when testing links and browser features, the file can also be served from a simple local static server.

> [!NOTE]
> This repository preserves the documentation site as a standalone artifact. The README describes the existing file and does not replace its technical content.
